# Remove Object

Firefox extension (140+) that adds a "Remove Object" context-menu item to
remove an element from a page.

## Usage
1. Right-click an element → "Remove Object". It gets a red outline.
2. Move the mouse to move the outline to the element under the cursor.
3. Click to remove the outlined element, or right-click to cancel.

Removal only affects the current page view; the element is back after a
reload.
